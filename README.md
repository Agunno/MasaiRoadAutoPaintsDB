# Masai Road Auto Paints Management System (MRAPMS)

## Overview

MRAPMS is a production-ready inventory and Point of Sale (POS) database built for Masai Road Auto Paints.

The project is designed using MySQL 8 and follows database design best practices to support:

- Inventory Management
- Product Management
- Purchasing
- Sales
- PIMA (Products Issued in Measured Amounts)
- Reporting
- Azure Database for MySQL
- Power BI dashboards

## Technology Stack

- MySQL 8
- Azure Database for MySQL
- Power BI
- Git
- Visual Studio Code
